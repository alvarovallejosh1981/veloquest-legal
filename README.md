# veloquest-legal

Sitio estático con los documentos legales de **VeloQuest** y el recurso web de eliminación
de cuenta, publicado en GitHub Pages.

## ⚠️ Este repositorio es una COPIA PUBLICADA

**La fuente de verdad es `web/` en el repositorio principal de VeloQuest (privado).** No
edites nada aquí: los cambios se hacen allí y se publican con el guion de sincronización.
Editar aquí crea dos versiones del mismo documento legal, que es justo lo que no puede
pasar con un texto que la gente acepta formalmente.

## Por qué existe por separado

El repositorio principal es privado y el plan de GitHub es gratuito, así que no puede
servir GitHub Pages. Estos documentos, en cambio, **tienen que ser públicos**: alguien debe
poder leer la política de privacidad antes de aceptarla, y sin necesidad de una cuenta.

## Estado

Los documentos llevan un banner de **BORRADOR**: están redactados contra el inventario real
de datos, pero **no han pasado revisión jurídica**. El banner se retira cuando la pasen.

Publicarlos aquí no los convierte en definitivos. Los publica para que se puedan **leer**,
que hasta ahora no se podía: el dominio al que apuntaba la aplicación no resolvía.

## Dominio

Provisional: `alvarovallejosh1981.github.io/veloquest-legal/`.

Cuando `veloquest.app` esté registrado, se apunta con un `CNAME` en este repositorio y se
actualizan las URLs en la aplicación. Las rutas no cambian.
